# Retrieval-Augmented Generation

Reserved for the future AI/RAG pipeline. Catalog information will be consumed through LIRA's backend and Koha REST API rather than direct database access.

- `ingestion/`: prepare catalog content for retrieval.
- `embeddings/`: future embedding workflows.
- `retrieval/`: future catalog context retrieval.
- `prompts/`: prompts and assistant instructions.

No vector database, embedding model, LLM, or RAG framework is selected yet.
